# 长按收藏交互

## 决策

采用方案 C「整行渐染 · 印章」作为正式实现方向：长按进度从行首向右渐染，收藏完成后在行尾显示倾斜星形印章，条目保留原时间位置；再次长按取消收藏。

渐染完成后整行保留主题强调色浅染，作为收藏状态的持续视觉标识；普通记录保持原背景，取消收藏成功后浅染淡出。

收藏窗口是收藏条目的删除出口。历史窗口中的右键操作对未收藏条目执行删除，对已收藏条目显示保护提示。

## 实现约束

- 长按反馈使用一次声明式动画；不要使用逐帧 GCD 计时器或 `Timer.scheduledTimer`。
- 历史列表中的单击选中、双击恢复和长按需要共享原生 clickCount 判定，并保留约 0.22 秒的起手宽限期。
- 如果列表容器无法稳定承载按压进度动画，应将按压行隔离到可控的 `ScrollView`/`VStack` 结构。
- 收藏状态变化不能重排历史顺序。
