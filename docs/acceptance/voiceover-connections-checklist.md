## 前置条件

- macOS，系统设置 → 辅助功能 → VoiceOver 已开启（`Command + F5`）。
- 至少一个已配对设备（用于出现每设备控件），连接方式可切换。
- 语言分别切到「简体中文」与「English」各跑一遍（`Loc` 按 `Locale.current` 选择 `zh-CN` / `en`）。
