# 富文本 R4 实机验收清单（可填写，2026-10-09）

配套方案：`docs/RICH-TEXT-R4-EXECUTION-PLAN-2026-10-09.md`。本清单用于在**独立环境**中逐项填写 R4 实机观察。它是人工核查表，**不是 CI 证据，也不是通过证明**；未填的格子默认 `UNKNOWN`。

## 1. 使用说明与结论词

- 结论只能取四种：`PREPARED` / `UNKNOWN` / `FAIL` / `PASS`。
- `PASS` 必须绑定源码/包指纹、应用版本与证据文件；无证据不得填 `PASS`。
- 证据类别分开：`本地自动测试` / `package` / `CI` / `device` / `双设备`，不得互相替代。
- fixture、本地测试、CI、宿主编译都不能写成 `device` 或 `双设备` 的 `PASS`。

## 2. 前置条件（全部满足前不得开始）

- [ ] 使用**独立 macOS 系统测试账户或 VM**（不是当前用户）；VM 已关闭宿主共享剪贴板、共享 TailSync 数据和个人钥匙串接入。
- [ ] 已**先记录环境**（见第 3 节），再采集。
- [ ] 真实 App 启动与系统剪贴板写入已获**人类明确授权**。
- [ ] 不读取已有系统剪贴板/真实历史；不停止日常 App；不覆盖旧包/旧 artifacts/用户 DB。
- [ ] 未修改产品代码、未绕过加密；不使用第三代理或后台 CLI。
- [ ] 未运行 `macos/scripts/verify_macos_bundle.sh`（它读写 general 剪贴板并占 TCP 19890）。
- [ ] 包内文件摘要与父代理候选清单一致，已在获授权的独立环境中放置候选；当前用户禁止启动。
